# 威胁模型

## 信任边界

SSH 验证对端身份并加密传输；应用仍以普通 Linux 用户身份运行。对该 Linux 账户具有 shell 权限的人可以执行账户允许的命令，产品白名单不会把既有 SSH 账户变成受限账户。

Linux 用户安装的桌面入口及可选自定义配置是本地可信输入。客户端只能发送服务端发现/注册的 ID，无法用请求添加 executable 或任意参数。系统应用本身可能打开文件、启动子进程或执行 shell；这是该 SSH 用户已有的能力，目录不是恶意应用沙箱。

## 必须保持的控制

- 使用严格 known_hosts 校验，主机未知或变化时停止，不默默 accept-new/no。
- 禁止密码出现在参数、URL、配置或日志；使用用户预先配置的 SSH 认证。
- 本地 subprocess argv 不等于远端 shell 安全。远端入口固定，业务请求在 stdin；不拼接客户端传入的 shell 片段。
- 检查 host/user/port/app_id/session_id，拒绝选项注入、控制字符和路径遍历。
- Agent socket 与会话目录仅当前用户可访问；Xvfb 需独立 Xauthority cookie，不用 `-ac`，不监听 TCP。
- 限制消息、PNG 尺寸、帧队列、应用数量和连接占用，避免资源耗尽。
- 不记录按键、剪贴板、画面、私钥内容。默认关闭不必要文件、打印、音频、摄像头及远程 URL 功能。
- 不自动安装 root 服务、修改防火墙、暴露公网、修改权限或生成长期授权。
- 固定 existing 入口由服务端配置 PID、可执行文件、显示号与 Xauthority。只转发经批准范围内的 X11 窗口；不向客户端暴露认证 cookie，不改变全局 XAUTHORITY 来切换连接。
- 自动发现的窗口以 XRes 本地客户 PID、同 UID、进程启动时间和窗口 ID 注册；点击时再验证。仅选中窗口及其关联弹窗进入会话，同进程其他主窗口仍被拒绝。只读列表不截取内容或发送输入，已有外部进程不归 Agent 所有。旧显式 existing 配置继续按批准进程接入。
- 远端图标在 Ubuntu 转为受限 PNG，客户端检查长度及格式头/尺寸；不直接插入远端 SVG、HTML 或文件 URL。
- 剪贴板仅由主动复制/粘贴触发。用 XRes 核验请求方/selection owner 的 PID，只允许目标应用及经同 UID、可执行文件核验的 GNOME Shell、KWin Wayland 或 Weston 桥接进程。Xwayland 的桌面合成器属于剪贴板信任边界，并非目标应用与其他同用户程序间的强隔离。控制端只接收对应请求 ID、窗口和有效期的复制回包；不后台轮询或记录剪贴板正文。图片/文件的主动跨端传输使用私有缓存，容量、保留期、路径校验和原文件保护见[剪贴板说明](clipboard.md)；文本正文不写入缓存。

## 限制

可信服务器可发送恶意窗口标题、尺寸或图像，Mac 端仍需验证。X11 会话中同 UID 的程序并非强隔离，同账户的其他进程可能读取会话数据。应用权限隔离请使用专用低权限账户或后续受控 sandbox。开发者预览不是经过外部安全审计的软件。

existing 接入会在原窗口上执行输入、缩放和关闭；PID 属性筛选不是对同用户恶意 X11 客户端的安全沙箱。原桌面的本地输入可能与远端输入相互影响，现有实现不支持两端协调控制。
