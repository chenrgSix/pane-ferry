窗渡 PaneFerry v0.1.3 开发者预览版，重点加入 Windows 发布、整桌面和系统声音，并改善 Windows → Mac 的画质与连续性。

### 下载

- **Windows x86_64**：`paneferry-v0.1.3-windows-x86_64-setup.exe`，按当前用户安装。
- **Apple Silicon Mac**：`paneferry-v0.1.3-macos-arm64.zip`，解压后将「窗渡 PaneFerry.app」放入应用程序。
- **Ubuntu x86_64**：推荐 `paneferry_0.1.3-1_amd64.deb`；也保留 `paneferry-v0.1.3-linux-x86_64.tar.gz` 用户目录安装包。
- `SHA256SUMS` 提供校验值，`BUILD-INFO.json` 记录各平台包的源码提交、构建环境和哈希。

### 主要更新

- Windows 支持应用窗口和按显示器连接整个桌面；对话框、子窗口和右键菜单在 Windows 合成后传输，修复焦点与点击问题。
- 完善全部窗口接管、自动接入新窗口、应用发现，以及「原画面／适配本机」显示设置。
- 优化 GPU 合成与纹理编码，保留软件回退；支持 Mac 接收 4:4:4 色彩，改善运动模糊、黑闪和周期性停顿，不要求独立显卡。
- 新增 Windows 系统声音：设备页独立开关、默认关闭，不采集麦克风，多窗口只播放一份声音。
- 音频加入短缺包补偿、有限自适应预缓冲和突发队列恢复，避免短暂网络抖动触发三秒重连。

### 升级

建议两端一起更新。先关闭接收窗口、退出旧启动器及发布组件，再安装新版；保留原设备身份、配对和配置。Windows 上运行中的 `paneferry-windows.exe` 也应退出后再安装。

系统声音在控制端「设备 → 对应 Windows → 接收这台设备的系统声音」开启。声音按设备独立运行，关闭画面后仍可收听；关闭声音开关停止。

### 验证与已知边界

- 用户已在 Mac → Windows 验证窗口和菜单操作、整桌面画面与输入，并反馈音频卡顿消失或明显减少；这不代表所有设备与网络均已验收。
- 功能提交 `42af83b` 的 Windows、Linux CI 通过；Mac 编译、音频和启动器测试通过。完整 Mac CI 中 WindowTree 的绘制反馈断言与 NetworkLatency 的 UI 线程超时断言仍有失败，本版本不宣称全部门禁通过。
- 安装包从同一版本提交构建，单独执行平台构建、相关单测和包校验；Mac 解压后校验主应用及两个辅助应用的版本与临时签名。
- Mac 包为 arm64，最低 macOS 13，在 macOS 15 构建；使用临时签名，未做 Developer ID 签名及公证。Windows 安装包未做 Authenticode 签名，系统可能提示来源未验证，请先核对来源和校验值。
- Linux 包在 Ubuntu 24.04 构建；GNOME 原桌面集成仍需要 GNOME 50，其他桌面版本未验收。升级 GNOME 扩展后保存工作并重新登录加载新版，安装过程不会自动注销。
- 系统声音第一版使用 Opus 和独立 QUIC 可靠流，仍可能受持续丢包影响；不含麦克风、按应用隔离音频、远端扬声器静音或严格音画同步。锁屏、安全桌面及权限保护窗口不在普通桌面接管范围。
