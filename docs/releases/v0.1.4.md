窗渡 PaneFerry v0.1.4 开发者预览版：Mac、Windows、Linux 统一管理界面，并完善 Linux 接收、声音和升级迁移。

### 下载

- **Windows x86_64**：`paneferry-v0.1.4-windows-x86_64-setup.exe`，按当前用户安装。
- **Apple Silicon Mac**：`paneferry-v0.1.4-macos-arm64.zip`，解压后将「窗渡 PaneFerry.app」放入应用程序。
- **Ubuntu x86_64**：推荐 `paneferry_0.1.4-1_amd64.deb`；另提供 `paneferry-v0.1.4-linux-x86_64.tar.gz` 用户目录安装包。
- `SHA256SUMS` 提供校验值，`BUILD-INFO.json` 记录各平台安装包的源码提交、构建环境和哈希。

### 主要更新

- 三端共用管理界面。工作台优先显示接收窗口，应用目录更紧凑，支持按设备收藏、最近使用和全局搜索；整桌面与全窗口接管保留独立按钮。
- 保存设备名称和连接地址。Linux 升级时可迁移旧管理界面的保存连接及显示、声音、接管偏好，公共界面已有配置优先。
- Linux 保留 GTK/GStreamer 原生接收，完善整桌面、4:4:4 色彩、输入法和剪贴板；同应用多会话共用接收进程，重复接入复用窗口，关闭单个窗口保留其他会话。
- 增加 Linux 系统声音支持，沿用按设备独立开关；完善音频停止、XWayland 关联窗口及安装组件解析。

### 升级

建议两端一起更新。先保存工作、断开接收窗口并退出旧启动器，再按平台安装新版。设备身份、配对和配置保留；无需重新生成邀请。Linux tar 和 Debian 包选择一种安装方式，避免系统版与用户目录版混用。

升级 GNOME 扩展后，需要保存 Ubuntu 上的工作，注销并重新登录桌面加载新代码；安装过程不会自动注销。独立 X11 应用不依赖 GNOME 扩展。

### 验证与已知边界

- 发布安装包从同一提交构建，附各平台构建记录和 SHA-256 校验值。前端、Rust、隔离桌面、原生接收与包装验证不等同于所有设备和网络的端到端验收。
- 本次发布没有新增端到端延迟对照数据，不将界面统一或构建成功表述为性能改善。
- Mac 包为 arm64，最低 macOS 13，在 macOS 15 构建；使用临时签名，未做 Developer ID 签名或公证。Windows 安装包未做 Authenticode 签名。
- Linux 包在 Ubuntu 24.04 构建；GNOME 原桌面集成仍要求 GNOME 50，其他桌面组合未验收。Linux 接收器需要 GTK/GStreamer，公共启动器需要 WebKitGTK 4.1。
- 系统声音不包含麦克风、按应用隔离或严格音画同步；锁屏、安全桌面及权限保护窗口不在普通桌面接管范围。
