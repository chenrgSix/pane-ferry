# 真实设备验收清单

当前只有原生窗口链路。2026-10-20 已在 Apple Silicon Mac 与 Ubuntu 26.04 的 xterm 上执行基础联调，具体记录见 `docs/validation.md`。单个应用通过不代表所有 Linux 图形应用兼容。

## 已覆盖的基础场景

1. 普通用户 Agent 在独立 Xvfb + Openbox 会话运行；私有 socket 为 0600、状态目录为 0700，不接管现有 GNOME/Wayland 桌面。
2. Mac 启动器通过系统 SSH 加载白名单和运行中会话；原生 WindowHost 显示真实 Ubuntu xterm 画面。
3. 键盘输入在远端执行并产生可核验结果；指针按钮和修饰键到达 X11，连接中断后释放按住的输入。
4. 重复 request_id 返回同一会话；已有控制端时拒绝第二控制端；启动器准备会话不抢占控制权。
5. resize 更新 geometry_revision；窗口隐藏再显示保留窗口 ID，不误报为销毁。
6. 完成 20 次重连，以及一次断开 30 秒后的恢复；重新附着收到快照和新图像。
7. 启动器退出重开后可读取远端会话并恢复原有窗口内容；Mac 红色关闭按钮只断开并退出宿主，远端应用保留并可重连；应用内部退出后从会话列表移除。
8. 接入原桌面已有 ChatGPT 窗口，保留进程和登录状态；输入、清空草稿与重新连接已验证。独立测试验证其他窗口被排除，停止 Agent 不结束原有进程。
9. 控制端 NSTextInputClient 的预编辑、Unicode 提交和复制回包关联通过本地测试；自建 GTK/X11 桌面已验证中文/emoji、多行粘贴、主动复制回传与无选择复制超时。原桌面 Firefox 的点击、中文输入及双向复制粘贴已由用户实测确认；新版 ChatGPT 尚未完成往返验收。

## 仍需验收

- 更多 GTK/Qt 应用、复杂菜单、弹窗父子关系、透明和遮挡情况下的画面完整性。
- 复杂中文输入法、精确候选框位置、原桌面 ChatGPT 的复制/粘贴，以及更多 Xwayland 系统授权、锁屏和焦点场景。
- 跨屏幕 DPI 热切换、Qt/传统 X11 应用缩放、双屏、休眠恢复、长时间断网及网络切换。GTK 1×/2× 重绘、窗口 resize 与输入已通过独立测试。
- 窗口销毁后的迟到帧、快速连续缩放、慢接收端、超大消息、无效 PNG、应用崩溃及 Agent 重启等故障矩阵。现有协议单元测试不能替代完整实机故障测试。
- 在真实硬件和网络条件下测量启动耗时、输入延迟、带宽、CPU 与持续运行稳定性。
- 安装、开机恢复、开发者签名、公证、升级与卸载。当前交付为本机开发包，联调服务为临时用户服务。
