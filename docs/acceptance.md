# 真实设备验收清单（未执行）

本次用户允许先不做实机测试。以下是交付后的检查计划，不是通过记录。

1. 在 Ubuntu 26.04 普通用户下安装运行依赖，原 GNOME/Wayland 会话保持不变。确认 Agent 无 TCP 公网监听，socket/会话目录仅用户可访问。
2. Mac 手工核验 SSH 指纹并建立登录。错误/未知主机密钥应失败，错误用户名和端口给出可诊断错误，不降级到无校验。
3. P0：Mac 启动器加载白名单；点击 xterm/Mousepad 得到独立 Xpra 窗口。输入、滚轮、调整大小、最小化、关闭均检查；不出现整个远端桌面。
4. P1：不启动 XQuartz 或 Xpra 客户端，使用自有 WindowHost。观察真实 Linux 窗口图像和输入反馈；仅本地 PNG 演示不合格。
5. 连续重复启动同一个 request_id 不能生成多个会话；不同 app/session 不串流；未知 app_id 被拒绝。
6. Mac 断开 30 秒，Linux 应用继续运行；使用会话 ID 重附着，窗口与未保存内容一致。主窗口关闭按 Linux 程序自身确认流程，不粗暴 kill。
7. 测试窗口销毁后迟到帧、快速 resize 的旧帧、慢连接、超大消息、无效 PNG、应用崩溃、Agent 重启。
8. P2/P3 才验收复杂菜单、弹窗父子关系、纯文本剪贴板、中文预编辑、Retina、双屏、休眠、20 次重连和视频滚动。当前未宣称完成。
9. 测量真实硬件/网络下启动与交互延迟，记录版本与测试条件，不用设计目标替代测量值。
