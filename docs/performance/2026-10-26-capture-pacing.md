2026-10-26。主要额外等待在采集和异步转换的调度：旧循环只在视频发送期限到达后推进两级处理，
原始 sample 和转换后的 sample 都可能额外等一轮。`317107f` 将非阻塞准备与编码发布的帧率节拍分开；
`5d12ddc` 补齐更早采集暴露的尺寸元数据时序问题。最终构建已部署到 Ubuntu。

19.908 ms / 11.80%。CPU 由服务 cgroup 累计 CPU 时间除以各轮观察时长计算，

## 定位证据与通用改动

临时诊断构建只控制自有 GTK 计数窗口，逐次核对原始 BGRx、I420 和 Mac 实际显示缓冲中的计数。
匹配帧附带 Linux 单调时钟时间戳；与同机 GTK 输入、绘制日志关联。下表来自探索性诊断旧版与 `317107f`，
各 30 个正式样本，使用原生产 EasyTier 路径；它不与最终直连正式样本混合统计：

| 阶段中位数，ms | 诊断旧版 | 诊断优化版 |
|---|---:|---:|
| Agent 读到输入 → 分发 | 0.347 | 0.040 |
| 分发 → GTK 输入回调 | 18.896 | 11.899 |
| GTK 输入回调 → 应用绘制记录 | 4.525 | 2.738 |
| 应用绘制记录 → 取到匹配原始 sample | 52.747 | 25.310 |
| 原始 sample → 取到匹配 I420 sample | 38.819 | 3.991 |
| 匹配 I420 sample → 开始编码 | 0.122 | 19.473 |
| 编码 | 2.372 | 1.832 |

“原始 sample → I420 sample”包含控制循环等待和实际颜色转换，不能称为转换器本身消耗 39 ms。
原始 sample 的时刻也是实际读取、核对计数的时刻，并非 PipeWire 首次通知的精确时刻。
新版将准备步骤提前后，编码发布仍要遵守 30 FPS 上限，因此匹配 I420 结果可能等待下一个发送期限。
阶段中位数不能直接相加，诊断本身及负载差异也会影响数值。

- `317107f`：每轮先处理输入，再推进非阻塞 raw 提交与 I420 收取；完成通知继续唤醒同一个控制循环。
  编码发布按协商帧率进行，去重、QoS、队列容量和窗口公平性保留。
- 该循环服务普通 Wayland 窗口、应用会话画面与整桌面后端，没有应用名称、IDEA 或 ChatGPT 分支。
  PipeWire 原始与转换 appsink、转换 appsrc 继续使用原来的有界策略，不新增中间 BGRx 裁剪或像素复制。
- `5d12ddc`：新尺寸 raw sample 可能先于 scope 几何到达。旧路径会丢弃不匹配 sample，
  静态应用随后不再重绘，便一直收不到新尺寸帧。现在最多保留最新一个原始 sample，scope 更新后重试；
  后来的 sample 替换旧租约，采集结束释放。旧几何的转换结果仍失效。
- 测试工具 `78a7486`、`e117ba2` 按窗口关联输入计数并追踪匹配像素，插桩只进入 git-archive 临时副本。
  最终 Agent 无 `_agent_stages` 字段，安装后另核对二进制与构建源文件。

## 最终正式测量条件与结果

- 同一台 Mac 与 Ubuntu，同一正式网络二进制和证书身份；临时独立 Mac 网络实例绑定 UDP 55848。
  `connection_opened` 确认真实对端 `192.168.1.254:42424`，Mac 路由为 `en0`。
  SSH 只用于管理夹具、部署和取日志；计时内输入及视频走 QUIC，没有关闭 TLS 或重新配对。
- 测试自有原生 Wayland GTK 窗口：源 1470×809 像素、1×；Mac 内容区 1467×805 点。
  相同逻辑网格、文字与每 33 ms 更新的小动画；H.264、VideoToolbox 硬件解码、30 FPS 协商上限及正常反馈自适应。
- 旧版为已部署基线二进制，新版包括两项修复且无诊断插桩。每轮明确部署对应二进制并记录 SHA-256；
  各轮重新创建独立夹具，不接入用户应用。顺序为旧、新、新、旧、新、旧、旧、新。
- 每轮 30 次方向键和 30 次点击，首次画面后等待 2 秒并排除每种操作 2 次预热；每版正式样本 240 个。
  逐次检查密度、可见性、帧尺寸及源端输入/绘制计数；全部正式轮次通过，全部慢样本保留。
- 起点为 Mac `SurfaceView` 输入处理，终点为 AVFoundation 返回与提交缓冲身份一致的 displayed pixel buffer，
  随后核对视觉计数。所有端到端差值使用同一 Mac 单调时钟，不相减跨机绝对时间。
  终点是 **renderer displayed-buffer availability**，不含实体键鼠硬件扫描、系统输入派发、最终桌面合成、
  屏幕扫描与面板响应，也不等同于直接测量 IDEA/ChatGPT 的实际业务操作。
