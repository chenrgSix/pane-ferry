# 192.168.1.254 直连与 EasyTier 的端到端对照

2026-10-26。在相同 1×、30 FPS 原生 Wayland 测试窗口上交错测量两条真实 QUIC 路径。
直连降低了 ping 往返时间，本轮软件端到端中位数没有观察到明确改善。

| 指标 | EasyTier：10.0.1.66 | 局域网：192.168.1.254 |
|---|---:|---:|
| 端到端中位数 | 118.435 ms | 118.770 ms |
| 端到端 P95 | 154.862 ms | 150.276 ms |
| 端到端最大值 | 197.892 ms | 169.301 ms |
| ping 均值，各 8 次、0% 丢包 | 9.217 ms | 4.383 ms |

直连端到端中位数比对照高 0.335 ms，P95 低 4.585 ms。
各轮中位数明显重叠：EasyTier 为 110.340–135.000 ms，直连为 108.152–126.778 ms。
这不支持将“ping 更低”直接解释为本轮整体跟手性有明显提升，也不能根据这次较小的最大值宣称尖峰已消除。

## 路径与条件

- Mac 的 `192.168.1.254` 路由为 `en0`，`10.0.1.66` 路由为 `utun4`；Ubuntu 确认 `enp1s0`
  同时具有 `192.168.1.254` 和 `192.168.1.26`。到 Mac 局域网地址的回程也为 `enp1s0`、源地址 `192.168.1.254`。
- 使用已配对设备的同一证书与身份进行验证，没有关闭 TLS 校验或重新配对。直连使用私有临时状态中的
  独立 Mac 网络实例，绑定临时 UDP 端口 62012；EasyTier 使用现有生产实例。两者使用同一个正式网络二进制。
- `connection_opened` 日志分别确认真实对端为 `192.168.1.254:42424` 和 `10.0.1.66:42424`。
  没有只改配置文件便假定现有缓存连接已改道。SSH 仍用于夹具管理和取日志，计时中的输入、视频均走对应 QUIC。
- 同一个已部署的正式 Agent、同一临时 WindowHost 探针、H.264、VideoToolbox 硬件解码、正常反馈自适应。
  协商上限均为 30 FPS；源像素 1470×809、缩放 1×，Mac 内容区 1467×805 点，逻辑网格与文字布局相同。
- 自有 GTK 窗口每 33 ms 更新小动画块；只注入该窗口的方向键和点击，不提交文字或访问剪贴板。
- 正式顺序为 EasyTier、直连、直连、EasyTier、直连、EasyTier、EasyTier、直连。每条路径 4 轮，
  每轮 30 次方向键和 30 次点击，共 240 个正式样本；等待首次画面 2 秒并排除每种操作 2 次预热。
- 起点为 Mac SurfaceView 输入处理，终点为 AVFoundation 显示缓冲与提交缓冲身份一致的时刻，随后核对视觉计数。
  所有差值使用同一 Mac 单调时钟；不包含键鼠硬件扫描、系统派发、最终桌面合成、屏幕扫描与面板响应。

## 阶段观测

| 阶段中位数 | EasyTier | 直连 |
|---|---:|---:|
| 输入处理开始 → 写出结束 | 0.263 ms | 0.279 ms |
| 写出结束 → 完整响应收到 | 105.194 ms | 105.081 ms |
| 响应收到 → 解析/解码完成 | 2.457 ms | 2.538 ms |
| 解码完成 → 主线程选帧 | 0.073 ms | 0.073 ms |
| 主线程选帧 → 显示缓冲可用 | 9.616 ms | 9.721 ms |

两条路径“发出后到回显收到”都约 105 ms，包含输入传输、应用响应、采集、编码和回程。当前软件记录
无法将这段全部归因给某个环节；网络 ping 只是辅助信息。阶段中位数不能直接相加。

## 异常轮次与验证

先做了 8 个样本的直连预检及两个各 60 个样本的探索轮次，均未混入正式统计。随后一轮直连在计数 4 之后，
测试窗口从 1×、1470×809 变成 2×、2940×1618。该轮只有一个正式响应，之后等待点击回显超时，
但视频连接仍在返回画面；最终接收序号为 2373。源端日志明确记录了缩放变化，因此整轮作为条件失效留档，
不将其作为正常 1× 延迟样本，也没有把它直接解释为直连网络超时。具体的缩放变化原因尚未定位。

`1f987ce` 给临时探针增加逐次输入前的源密度、尺寸、可见性及已显示帧尺寸检查，检测到布局变化便立即停止注入。
单测与探针构建通过。使用同一更新后探针重新交错完成八轮；两组全部核对实际 1×、30 FPS、H.264、硬件解码、
有序输入计数、对应源端绘制与同端时间戳。P95 使用最近秩，全部正式慢样本均保留。
