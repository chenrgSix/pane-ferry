# Ubuntu 与 Windows 的桌面、弹窗和操作体验对照

已从远端 `main` 快进到 `02ccb82`，按“完整桌面、弹窗与操作体验”对照实现。
Ubuntu 已有按显示器连接的完整桌面模式；本轮补上大屏接入和源端光标，并更新本机 Agent。
应用窗口模式仍有结构差异，不能将这两项补齐描述为全部达到 Windows 的体验。

## 两端差异

| 项目 | 最新 Windows 实现 | Ubuntu 当前实现 |
| --- | --- | --- |
| 完整桌面 | 每个显示器一条 WGC 流，含光标 | 每个显示器一条 Mutter/PipeWire 流；本轮启用内嵌光标 |
| 4K、竖屏、宽屏 | 原始采集与视频预算分开，超限等比缩小 | 本轮补齐；此前 3840×2160 因超过 8M 像素被直接过滤 |
| 桌面内菜单、对话框、其他应用 | 显示器内容自然包含这些窗口 | 同样包含；不需要给每个弹窗重新创建远端窗口 |
| 单应用聚合 | 发布端默认合成主窗口、所属对话框和菜单 | 原生 Wayland 提供可选的“应用会话画面”；XWayland 主要仍是分窗口流 |
| 键鼠、文本 | Windows 输入与焦点校验 | GNOME Portal/libei 授权、逻辑坐标映射和焦点文本桥 |
| 全色度与系统音频 | 协商的 444 atlas 与可选 Opus 音频 | 当前 Linux Agent 未接入这两条 Windows 路径 |

需要整个桌面一起操作时使用工作台的“整桌面 → 连接桌面”；“接管所有窗口”仍是一组应用会话，
不会变成完整显示器画面。Ubuntu 的应用会话画面仍按发布端能力和显示偏好选择，不能把 XWayland
直接标成支持场景来绕过现有范围、输入与采集校验。

## 本轮实现

- 显示器原始尺寸上限为 8192/边、32M 像素；视频仍限 4096/边、8M 像素。
  预算内保留原像素，超限时等比缩小，不裁切、不设置源端显示模式。
- 显示器列表保留源尺寸；会话初始元数据与后续实际帧使用相同的画布计算。
  PipeWire 转换直接从完整源区域生成目标 I420，不先裁掉源画面或申请一幅完整 CPU 裁剪副本。
- 单窗口 CropConverter 的默认目标仍等于原裁剪区域，奇数尺寸仍补黑边；缩放仅用于超预算的桌面。
- 鼠标仍通过实际视频画布映射回显示器逻辑位置；检查 HiDPI、负原点和越界拒绝。
- 桌面 `RecordMonitor` 使用 `cursor-mode=1`，由 Mutter 把光标合入视频。
  应用专用流的光标策略保持原实现。[Mutter API 定义](https://mail.gnome.org/archives/commits-list/2021-November/msg04072.html)

## 验证

旧版为 `02ccb82` 的独立 release 二进制。新旧版使用同一私有 GNOME、临时 HOME、测试自有 GTK 窗口与指针，
没有采集或控制实际登录桌面的应用。测试解码真实 H.264 像素，而不是只看窗口元数据。

| 源显示器 | 新版实际解码画布 | 结果 |
| --- | --- | --- |
| 1600×900 | 1600×900 | 移动光标、对话框、嵌套弹窗、其他窗口及重连通过 |
| 3840×2160 | 3770×2120 | 同上，保留源显示器模式；覆盖 GNOME 自动 HiDPI 布局 |
| 2160×3840 | 2120×3770 | 同上，竖屏方向与坐标正确 |

三组均检查：弹窗和其他应用出现时视频流号连续；桌面 resize/close 请求被拒绝；断开后恢复从 IDR 开始，
自有应用继续运行；测试前后的显示器布局相同。旧版 4K 测试得到空显示器列表；旧版普通桌面的光标移动检查超时。

- 工作区测试 **157 项通过**，另显式执行 **11 项**原生 GStreamer 编码/像素/租约回归。
- 显示器 Python 回归 5 项、输入授权单元回归 4 项通过；Wire、接收边界及 Wayland 采集检查通过。
- 实际 libei/libeis 与私有门户检查通过，覆盖键鼠、按下/释放、滚动、撤销、重连、令牌轮换和取消。
  这是自有 EIS 接收器，不将它声称为真实 GNOME 桌面上的端到端输入验收。
- 原生 Wayland 应用聚合的 H.264 像素检查通过，包含对话框、嵌套菜单、同 PID 无关窗口隔离和重连。
  分窗口树回归也通过，包含短生命周期弹窗及父子关系。

新增复现入口：

```sh
python3 tests/e2e/wayland_smoke.py --agent /absolute/paneferry-agent --desktop-only
python3 tests/e2e/wayland_smoke.py --agent /absolute/paneferry-agent --desktop-only --desktop-size 3840x2160
python3 tests/e2e/wayland_smoke.py --agent /absolute/paneferry-agent --desktop-only --desktop-size 2160x3840
```

早期测试探针选错 Clutter seat 获取方法，后修正；首次 4K 探针把物理坐标当成 GNOME 的逻辑坐标，
后按私有输出的实际逻辑矩形修正，未为适配探针修改产品输入映射。工作区首次构建缺少新增 Opus 依赖所需的 CMake，
随后只在临时目录解包 CMake/运行库，完整重跑通过，没有安装系统包。以上失败日志均保留。
