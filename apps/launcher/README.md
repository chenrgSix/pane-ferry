# Tauri 启动器

Tauri 2 + Vue 3 管理本机共享、设备配对、应用目录和运行窗口。每台设备同时可发布与接收，产品只使用配对 QUIC；Mac 包含 Swift 发布器、原生接收窗口和公共 Rust 网络组件。

## macOS 构建

需要已有 Rust、Node.js、Xcode Command Line Tools。运行 `cd apps/launcher && ./scripts/build-macos.sh`。产物在 `src-tauri/target/release/bundle/macos/`，为本机临时签名的开发包，尚无 Apple Developer ID 签名和公证。单独 `npm run dev` 仅预览界面，没有本机服务能力。

## 配对与恢复

左侧菜单按用途分为应用工作台、设备管理、本机共享、显示设置和连接记录。工作台只展示所选设备的应用与运行窗口；可通过顶部的“应用来源”切换设备。设备配对、地址更新与撤销在“设备管理”，共享开关与权限在“本机共享”，应用会话显示偏好与默认帧率（30/60，默认 60）在“显示设置”。新启动和新画布统一请求普通 1×，不跟随 Mac Retina 自动加倍；旧启动缩放偏好会清除。切换菜单保留当前设备、搜索和运行状态，不重新启动应用。连接记录注明来源设备，仅保留本次启动器运行期间最近 20 次操作。

两端打开 窗渡 PaneFerry。一端生成邀请，另一端填写对方地址（通常 `IP:42424`）和邀请完成双向配对。邀请五分钟内有效、仅限一次，需通过可信方式传递。选择设备后读取应用与窗口；共享开关和系统权限仍由各自本机控制，见[传输指南](../../docs/native-transport.md)和[Mac 发布指南](../../docs/mac-publishing.md)。

设备以持久 UUID 和证书标识。地址可更新，撤销一台设备只影响该设备；目录缓存、未确认的启动请求、窗口和恢复任务按设备隔离。新接口只接受 `peerId`，不接受主机、账号和 SSH 端口。

连接中断后按 1、2、4、8、15 秒退避重试，网络恢复事件会提前触发。原生窗口保留画面、大小和分辨率模式，恢复原 session ID；断线期间不重放输入、剪贴板和关闭操作。远端会话已退出时不另开应用。配对被撤销或证书改变时不能建立连接，需要重新配对，没有其他传输回退。

应用目录按设备缓存，自动恢复只刷新窗口和会话；安装或卸载应用后点击“刷新应用”。未收到首次启动响应时保留 request ID，避免重复打开同一应用。切换当前浏览设备不改变已有宿主的连接目标。

## 旧配置迁移

新版启动器删除本应用原有的 `ssh-connections.json` 密码文件，移除浏览器中的 SSH 设备配置和相应缓存。已配对 QUIC 设备的选中状态、目录缓存和未确认启动请求保留。不会读取旧密码、将 SSH 主机转换为受信任设备，或修改系统 `~/.ssh`。旧版用户需要通过设备邀请配对；系统 SSH 可继续用于开发部署与排障。

## 验证边界

“宿主已启动”不等于“远端画面已呈现”。实际两机、AppKit/GTK、恢复、剪贴板和多节点隔离的记录见[验证记录](../../docs/validation.md)。尚未把本机三节点测试称为三台物理设备验收；长期运行、休眠和切换网络仍需继续验证。
